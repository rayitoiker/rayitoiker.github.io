# NEON//SURVIVAL

Web estática humorística para jóvenes.

## Archivos
- index.html — estructura de la web
- style.css — diseño, responsive y animaciones
- script.js — test interactivo, modo pánico, mensajes aleatorios y compartir

## Cómo abrirla
No necesita servidor ni instalación:
1. Descarga la carpeta.
2. Abre `index.html` con cualquier navegador.

También puedes subir los tres archivos a GitHub Pages, Netlify, Vercel o cualquier hosting estático.
